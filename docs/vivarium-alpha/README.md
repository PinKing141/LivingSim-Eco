# Vivarium Alpha Roadmap

Vivarium Alpha is the production phase that begins **only after** the LivingSim-Eco simulation foundation passes every Foundation Exit Gate and is frozen as `LivingSim-Eco v0.1`.

The foundation answered:

> Can the ecosystem work autonomously, deterministically, at scale, for deep time?

Vivarium Alpha answers a different question:

> **Can someone enjoy watching, understanding, and becoming invested in this living world for hours without controlling it?**

This is not Slice 12. It is a separate roadmap with a separate purpose, quality bar, and exit gate.

---

## Entry criteria

Do not start implementation of Vivarium Alpha until all are true:

- the Foundation Exit Gate passes,
- `LivingSim-Eco v0.1` is tagged,
- benchmark seeds and gate results are archived,
- deterministic and save/reload hashes are captured,
- performance baselines are recorded,
- simulation rules are frozen as the Alpha baseline.

Exploration documents and visual experiments may exist before this point, but production Alpha work does not begin until the foundation is green.

---

## Alpha production sequence

1. **Foundation Freeze & Handoff** — turn the simulation foundation into a protected production baseline.
2. **Phase 1: Application Shell** — create/load flow, seed entry, save/session flow, pause and time controls.
3. **Phase 2: Observation** — camera, zoom, selection, follow modes, overlays and graphs.
4. **Phase 3: History & Lineage** — ancestry, descendants, population history, event detection and timeline.
5. **Phase 4: Visual Prototyping & Direction Lock** — test competing presentation systems using the same simulation and select one through evidence.
6. **Phase 5: Watchability & Experience Polish** — make long observation sessions readable, smooth, informative and emotionally engaging.
7. **Alpha Exit Gate** — prove the observer experience works before expanding ecological breadth.
8. **Ecological Breadth Entry Gate** — only then unlock major new content/system expansion.

## Production philosophy

This roadmap applies large-studio production techniques where they improve quality and predictability, while avoiding bureaucracy that provides no value to a small team.

Use:

- vertical slices,
- milestone entry/exit gates,
- feature ownership,
- definition of done,
- performance budgets,
- regression baselines,
- automated smoke/soak tests,
- usability testing,
- build configurations,
- feature flags,
- bug severity and triage,
- content locks,
- risk registers,
- telemetry/profiling builds,
- save-version discipline,
- accessibility from the start.

Do not imitate AAA team size, meeting load, or process overhead.

The objective is **AAA-style quality discipline, not AAA-style bureaucracy**.

---

## The Alpha rule

No major ecological breadth expansion during Alpha unless a missing ecological element is proven necessary for the observer experience.

The simulation is now the engine.

Alpha is about exposing, explaining and presenting what that engine already does.
