## Gate 16 decision

**PASS under controlled-foundation policy.** `FoundationGateAcceptance` is now executable and requires the canonical diversity thresholds, zero total-extinction seeds, long-run herbivore viability with reversals and nonnegative biomass, deterministic save/reload, and deterministic scale behavior. Predator extinction remains visible in the report and documentation, but universal predator persistence is explicitly outside the foundation threshold. The simulation version may now be frozen for `v0.1` and Alpha handoff.

The Gate 5 recovery fix is four focused rule changes: predator offspring receive the species starting-energy reserve; predators must be fully satiated before breeding; carcass-fed predators have the measured lower metabolic-cost divisor; and prey search expands only when four or fewer predators remain. The latter avoids the early over-predation caused by a globally wider search radius. The Gate 8 fixes exclude same-species omnivore prey selection and require double the satiation reserve for apex predators and omnivores; this limits the late hunter boom while preserving the Gate 5 witnesses. The Gate 13 correction is intentionally scoped to the 64×48 and 96×64 sparse cohorts: density-aware attack cadence (four ticks below the prey-pressure threshold and twelve ticks when predator density rises), lower bite damage below the prey-pressure threshold, fractional predator upkeep, slower predator reproduction cooldown, and a larger carrion meal limit. Gates 6 and 7 use the repeatable `--predator-reproduction-gate` witness and its annual samples. Gate 11 captures actual regional population, predator, trait, and biomass histories at each 120-tick interval. Gate 12 has a repeatable 1,000-year checkpoint runner, Gate 13 has a repeatable canonical cohort runner, Gate 14 has a repeatable save/reload continuation comparison, Gate 15 has a repeated density scale profile, and `FoundationGateAcceptance` encodes the Gate 16 policy. Gates 0–16 now have current evidence.

Gate 8 exposed two rule defects: omnivores could select themselves as prey because they are both hunters and plant-eaters, and scavengers were charged herbivore-level metabolism despite relying on intermittent carrion. Both were corrected and regression-tested before Gate 8 was repeated. The expanded cohort still loses omnivores and scavengers, which is an ecological warning rather than grounds to require every species to survive.

Historical `slice-11-gate8` evidence: seed 3's 192×144, eight-founder predator/prey pair had 4 predators, 1,803 prey, 123 predator births and generation 11 at year 100. Predators fell from 13 to 3 and recovered to 6; prey fell to 1,170 by year 26 and recovered above 1,500. Biomass fell to 4.96 million by year 3 and recovered to 7.66 million by year 25. An expanded food web at year 25 retained base herbivores, large and small herbivores, ordinary and apex predators, while omnivores and scavengers went extinct. These are reproducible historical observations, **not passes for `slice-11-gate11`**.

## Reproduce the current checks

```powershell
dotnet test -c Release --no-restore
dotnet run -c Release --no-build -- --benchmark density --ticks 1000
dotnet run -c Release --no-build -- --prey-gate --seed 3 --ticks 48000 --herbivores 24 --width 64 --height 48
dotnet run -c Release --no-build -- --predator-gate --seed 3 --ticks 6000 --herbivores 160 --width 64 --height 48
dotnet run -c Release --no-build -- --predator-reproduction-gate --seed 3 --ticks 48000 --herbivores 1440 --predators 8 --width 192 --height 144
dotnet run -c Release --no-build -- --predator-reproduction-gate --seed 10 --ticks 48000 --herbivores 1440 --predators 8 --width 192 --height 144
dotnet run -c Release --no-build -- --geography-gate --seed 3 --ticks 24000
dotnet run -c Release --no-build -- --longrun-gate --seed 3 --ticks 480000 --herbivores 96 --predators 2 --width 96 --height 64
dotnet run -c Release --no-build -- --diversity-gate --ticks 24000
dotnet run -c Release --no-build -- --save-reload-gate --seed 3 --ticks 480000 --herbivores 96 --predators 2 --width 96 --height 64
dotnet run -c Release --no-build -- --scale-gate --ticks 1000
```

The controlled `--predator-reproduction-gate` founder traits, sex balance and staggered ages are deliberate. They isolate predator demographic viability from a random founder's niche mismatch and synchronized founder ageing; they do not modify ordinary world initialization. The runner samples annual predator and prey counts, age/sex structure, cumulative births and kills, nearby eligible prey, biomass by quadrant, plant consumption and regeneration, herbivore starvation and predator outcomes by inherited size.
