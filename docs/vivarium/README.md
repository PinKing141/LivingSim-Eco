# LivingSim: Vivarium

> Working concept and development documentation. The project direction is defined at a high level, but the final visual style and rendering technology are intentionally **not locked** during the simulation-foundation phase.

LivingSim: Vivarium is an observer-first artificial-life ecosystem simulation. A deterministic seed creates a world, life is introduced, and the player watches survival, competition, migration, reproduction, ecological collapse, recovery, and evolution emerge without direct intervention.

## Next production roadmap

Once every foundation/ecology gate passes and `LivingSim-Eco v0.1 - Simulation Foundation` is frozen, development moves into a separate roadmap:

- [Vivarium Alpha Roadmap](../vivarium-alpha/README.md)

Vivarium Alpha is **not Slice 12**. It turns the proven simulation into the actual observer game: application shell, observation, history/lineage, visual direction, watchability, production quality and Alpha exit validation.

## North star

Everything added to the project should strengthen at least one of these:

1. The quality of the simulation.
2. The readability of the natural history it produces.
3. The pleasure of watching that history unfold.

Features that turn the player into an ecosystem manager should be treated as a separate mode or rejected unless the core vision changes.
